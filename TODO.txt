   Currently a '\b' (backspace character) is inserted where the cursor is
   before running it through Markdown. Then, after Markdown processing, that is
   replaced with an HTML tag which the user interface scrolls to in order to
   get the same spot in the fancy text, as the user double clicked in the

     console.log(r.toString(), r.startContainer, r.startOffset, r.endOffset)
   })
   ----------------------------------------
